## What We Build

Drinking Dragon Studios is a bespoke web development studio producing cinematic public sites and operationally serious member platforms for communities that deserve better than a template.

Our portfolio spans martial arts clubs, international federations, medical telemetry systems, publishing imprints, and language learning tools — each built as its own tenant, sharing only quality primitives, never a generic look.

## How We Work

- **Design-first.** Three reference studies before a line of code. Visual verification at every meaningful change. Mobile-first, accessible to WCAG 2.2 AA, Apple-class craft.
- **Isolated tenants.** Every site gets its own repository, its own database, its own secrets, its own release cadence. One site's incident never reaches another.
- **Safeguarding by default.** Minors' data, health records, voting ballots, and medical telemetry get stricter treatment at the design stage — not retrofitted.
- **Operationally serious.** Every deploy goes through CI gates, accessibility audits, visual regression checks, and (for sensitive sites) independent security review.

## Platform

Our shared foundation — [`drinking-dragon-studios/platform`](https://github.com/drinking-dragon-studios/platform) — is a private monorepo providing:

- Accessible UI primitives built on Radix
- A brand system of design tokens, zones and themes
- Authentication, database, email, audit, and observability packages
- The `dds` CLI for provisioning new sites with isolated infrastructure

Per-site repositories consume this foundation and add their own identity, content, and data.
